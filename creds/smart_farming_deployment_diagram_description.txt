### Option 1: Exact Match (Crop Recommendation System Only)
The component diagram depicts the architecture of a Crop Suitability Recommendation system. It includes a Device containing a web application labeled “SmartFarming” (Crop Recommendation System). The Crop Details Input Interface component collects user inputs (soil chemistry and climate parameters), which are then processed by the machine learning models: the Crop Recommendation Model (Random Forest and Support Vector Machine). The results from these models are stored in the Session component under “Crop Suitability Data.” The session then displays the recommendation data to the user through the web application interface. The diagram outlines how the system’s components interact to deliver the crop prediction results.

### Option 2: Complete Full-System (Includes Plant Disease Detection)
The component diagram depicts the architecture of a Smart Farming system. It includes a Device containing a web application labeled “SmartFarming” (Smart Farming Decision Support System). The Crop Details Input Interface and Leaf Image Upload Interface components collect user inputs and uploaded files, which are then processed by the machine learning models: the Crop Recommendation Model (Random Forest and Support Vector Machine) and the Disease Detection Model (MobileNetV2 and Custom CNN). The results from these models are stored in the Session component under “Crop Suitability Data” and “Leaf Diagnostics Data,” respectively. The session then displays the prediction and diagnostic data to the user through the web application interface. The diagram outlines how the system’s components interact to deliver the recommendation and diagnostic results.
