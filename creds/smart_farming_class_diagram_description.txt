### Option 2: Complete Full-System (Includes Plant Disease Detection)
The class diagram represents a structured smart farming decision support system that is composed of four core classes: User, AgriculturalData, CropRecommendationModel, and DiseaseDetectionModel. Symmetrically, the DiseaseDetectionModel acts as the image-processing engine, leveraging MobileNetV2 and custom Deep CNN attributes via is_plant_image() and predict() to deliver visual pathology diagnostics on leaf image files uploaded by the User.

In the class diagram it explains that the CropRecommendationModel and DiseaseDetectionModel classes are used internally and are not directly accessible by users. This encapsulation ensures that prediction and deep-learning diagnostic logic is kept separate from user interactions, making the system modular and easy to maintain. Each class has a clear role: User submits data, AgriculturalData and LeafImage hold input features, and the respective CropRecommendationModel and DiseaseDetectionModel handle the prediction processes. This separation keeps the system well-organized and focused.
